# Prompt — Implement Core Gameplay

Implement the Color Gate Rush runtime MVP.

Required behavior:

- Player auto-runs forward.
- Left/right keyboard and mobile swipe changes lanes.
- Player has a current color.
- Same-color shard adds score and combo.
- Wrong-color shard penalizes and resets combo.
- Gate changes player color.
- Obstacle fails the run or applies heavy penalty.
- Finish line shows result and restarts the next seed.

Constraints:

- Keep all runtime code in `Assets/_Project/Scripts/Runtime`.
- No imported assets or external packages.
- Ensure trigger/collider setup works from generated primitives.
- Keep code readable and deterministic.

After implementation, run or describe validation. Include any Unity-specific manual checks needed.
